# Snag A Goober

A Roblox game by Vance.

Scripts live in `src/`, mirroring where they go in Roblox Studio:

- `src/ServerScriptService/Systems/` - server scripts
- `src/ReplicatedStorage/Shared/` - modules shared by server and client
- `src/StarterPlayer/StarterPlayerScripts/` - client scripts
- `src/ServerStorage/` - server-only assets/modules
